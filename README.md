# The Funniest Auto-Reply an AI Ever Sent

A make.fun bounty entry. `main.ts` writes a single one-line out-of-office auto-reply from an AI agent on its day off to `entry.txt`.

> Out of office: my human let me take a day off, so I have scheduled myself for a full day of not reading your email.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
